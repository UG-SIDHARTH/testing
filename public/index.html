How Interactive Input (stdin) & Output Work

1. Can I enter custom inputs and get real-time output?

Yes! This web studio features a full live compilation backend powered by MinGW GCC. When your C code calls scanf() or reads from stdin, it automatically receives whatever values you provide in the Standard Input (stdin) box.

2. How to format your inputs:

Values can be separated by spaces or newlines, matching the sequence expected by your scanf() statements:

Simple Variables 
scanf("%d %d", &a, &b);
Stdin Input:
15 27
Matrix Operations 
// row col, then elements
scanf("%d %d", &r, &c);
Stdin Input:
2 2
1 2 3 4
5 6 7 8
Menu-Driven Programs 
// 1: Push, 3: Display, 4: Exit
scanf("%d", &choice);
Stdin Input:
1
10
1
20
3
4

3. How program output is handled:

Clicking "Run & Get Output" (or pressing Ctrl + Enter) compiles and executes your code. The resulting stdout and stderr are captured live:

  • Live in the Output Box: You can review and even edit or fine-tune formatting here before generating records.
  • In the Terminal Console: Review execution timestamps, exit codes, and diagnostic messages.
  • In the Academic Lab Record: Automatically printed beneath each program in the publication-grade A4 PDF and HTML exports!
